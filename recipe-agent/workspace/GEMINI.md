# Workspace Guidelines: Recipe Generator

## Output Structure
Every generated recipe must follow this structure:
1. **Title & Description**
2. **Prep Time / Cook Time / Servings**
3. **Ingredients** (categorized if necessary)
4. **Instructions** (numbered steps)
5. **Chef's Notes / Variations**

## Context management
Read previously generated recipes in `./recipes/` directory to avoid repetitions and to get inspiration and context.

## File Management
- Save finalized recipe outputs to the `./recipes/` directory as Markdown files.
